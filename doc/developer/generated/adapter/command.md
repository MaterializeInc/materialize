# adapter::command

Defines the `Command` enum — the complete set of messages that external clients (pgwire, webhooks, internal tools) send to the coordinator — and the `ExecuteResponse` / `ExecuteResponseKind` enums that the coordinator returns.
`Command` covers session lifecycle (`Startup`, `Terminate`), SQL execution (`Execute`, `Commit`), authentication (`AuthenticatePassword`, SASL variants, `CheckRoleCanLogin`), streaming data ingestion (`StartCopyFromStdin`), audit event injection (`InjectAuditEvents`), and several variants that offload work from the coordinator's main loop: `ExecuteSlowPathPeek`, `ExecuteSubscribe`, `ExecuteCopyTo`, `CopyToPreflight`, `ExecuteSideEffectingFunc`, `LookupConnection`, `RegisterFrontendPeek`, `UnregisterFrontendPeek`, `ExplainTimestamp`, and `FrontendStatementLogging`. `LookupConnection` resolves a raw connection ID to its `ConnectionId` handle and authenticated role; holding the returned handle prevents the raw ID from being reused, which the frontend peek sequencing relies on to ensure RBAC checks and the subsequent `ExecuteSideEffectingFunc` act on the same connection. Two variants manage scoped feature-flag overrides: `UpdateScopedSystemParameters` carries the desired sparse `ScopedParameters` and an optional `ScopedParametersScope` bounding which objects' rows may be pruned; `InstallScopedSystemParameterFrontend` shares a new `Arc<SystemParameterFrontend>` with the coordinator so create-time scoped resolution can evaluate synchronously. `RegisterConnectionCancelWatch` installs a connection-scoped cancellation watch, returning a receiver that fires when cancellation is requested; each registration replaces any prior channel so the caller cannot observe a cancellation aimed at an earlier statement. `CreateInternalSubscribe` creates a subscribe that writes no `mz_subscriptions` row, used by frontend-sequenced read-then-write (DELETE/UPDATE/INSERT...SELECT) operations via OCC. `AttemptWrite` submits a write attempt: `write_ts: Some(ts)` pins the write to an exact timestamp and reports `WriteResult::TimestampPassed` if the table has moved past it; `write_ts: None` rides the next group commit with a coordinator-chosen timestamp. `DropInternalSubscribe` drops an internal subscribe; it is fire-and-forget.
`ExecuteResponse` enumerates every possible result of a SQL statement execution, from `CreatedTable` to `SendingRowsStreaming`; `generated_from` maps each `PlanKind` to its permitted response kinds. `CreateMetricSink` maps to `[CreatedMetricSink]`, and `ExecuteResponse::CreatedMetricSink` carries the tag string `"CREATE METRIC SINK"`.
`CopyFromStdinWriter` carries parallel `mpsc` batch sender channels and a `oneshot` completion receiver that pgwire uses to stream raw byte chunks to background batch-builder tasks and then commit the resulting `ProtoBatch` values during `COPY FROM STDIN`.
