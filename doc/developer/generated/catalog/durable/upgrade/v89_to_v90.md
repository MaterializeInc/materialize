# catalog::durable::upgrade::v89_to_v90

Migrates catalog state from version 89 to version 90.

The only structural change is adding `arrangement_compression: bool` to managed clusters, their in-flight reconfiguration targets, and cluster replicas. Every affected record is backfilled with `false`.

The `upgrade` function accepts a full v89 state snapshot and returns one `MigrationAction::Update` entry for each managed cluster and each cluster replica. Unmanaged clusters have no `ManagedCluster` variant and are passed through without a migration action. All other record types are unchanged.

The three migration helpers correspond to the three affected record types:

- `migrate_cluster` — rewrites a managed `Cluster` record, delegating managed-variant fields to `migrate_managed`.
- `migrate_managed` — sets `arrangement_compression: false` on a `ManagedCluster` and forwards any in-flight reconfiguration to `migrate_reconfiguration`.
- `migrate_reconfiguration` — sets `arrangement_compression: false` on the `ReconfigurationTarget` inside a `ReconfigurationState`.
- `migrate_replica` — sets `arrangement_compression: false` on the `ReplicaConfig` of a `ClusterReplica`.

Structurally-compatible fields (those shared verbatim between v89 and v90) are transferred via `JsonCompatible::convert`, which is macro-asserted for each type pair at the top of the file.
