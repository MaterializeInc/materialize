# catalog::durable::upgrade::v90_to_v91

Migrates catalog state from version 90 to version 91.

The only structural change is adding `ephemeral_owner_session: Option<Uuid>` to `ItemValue`. Every `Item` record is rewritten with the field backfilled as `None`.

The `upgrade` function accepts a full v90 state snapshot and returns one `MigrationAction::Update` entry for each `Item` record. All other record types are unchanged and produce no migration actions.

The explicit rewrite is required even though serde would default the missing field to `None` on read. A later edit to an item retracts the record by writing its v91 encoding (with `ephemeral_owner_session: None`) at diff -1. Without the backfill, the stored record lacks the field and the retraction does not match it, leaving the collection with negative multiplicity.

The `migrate_item` helper transfers all `ItemValue` fields verbatim (via `JsonCompatible::convert` for structured sub-fields) and sets `ephemeral_owner_session: None`.

Structurally-compatible fields shared verbatim between v90 and v91 are transferred via `JsonCompatible::convert`, which is macro-asserted for each type pair at the top of the file.
