# catalog::durable::upgrade::v91_to_v92

Migrates catalog state from version 91 to version 92.

This is a no-op migration. v91 to v92 adds a `MetricSink` variant to four existing enums — `CatalogItemType`, `ObjectType`, `CommentObject`, and the audit log's `ObjectType` — but no stored record can use a variant that did not previously exist, so every v91 record reads back as valid v92.

Metric sinks are stored as ordinary `Item` records (like other catalog objects); there is no separate durable record type for them. The item type is recovered at read time from `create_sql`.

The `upgrade` function accepts a v91 state snapshot and returns an empty `Vec`, producing no migration actions.
