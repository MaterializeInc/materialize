# mz-expr::scalar::func::impls::jsonb

Provides scalar function implementations for `jsonb` datums: subscript operators, `jsonb_array_elements`, `jsonb_each`, `jsonb_object_keys`, type-coercion casts, `jsonb_build_object`, `jsonb_build_array`, `jsonb_pretty`, and containment checks.
Also provides `parse_catalog_id` (converts catalog JSON-serialized IDs into string format like `u1`, `s2`, `p`), `parse_catalog_privileges` (converts catalog JSON-serialized privilege arrays into `mz_aclitem[]`), `parse_catalog_acl_mode` (converts a catalog JSON-serialized `AclMode` bitflags object of shape `{"bitflags": <u64>}` into a PostgreSQL ACL char-code string, e.g. `{"bitflags": 514}` → `"ar"`), `parse_catalog_create_sql` (parses a catalog `create_sql` string into a JSONB object with type and additional fields depending on the statement: for connections, a `connection_type` field; for materialized views, `cluster_id` and `definition`; for views (`CreateView`), `definition` (the query body in stable AST form, with a trailing semicolon appended for PostgreSQL compatibility); for tables (`CreateTable`), no additional fields; for tables from source (`CreateTableFromSource`), a `source_id` field; for sources (`CreateSource`), `source_type`, `cluster_id`, `connection_id`, `envelope_type`, `key_format`, and `value_format`; for webhook sources, `source_type` and `cluster_id`; for subsources, `source_type` and `of_source_id`; for metric sinks (`CreateMetricSink`), `cluster_id` and `from_id`), `parse_postgres_source_details` (decodes a Postgres source `create_sql` to extract `slot` and `timeline_id` from the hex-encoded `DETAILS` proto option, returning `{"slot": <text>, "timeline_id": <u64|null>}`; returns JSON `null` for non-Postgres-source statements), and `parse_kafka_source_details` (extracts `topic`, `group_id_prefix`, and `connection_id` from a Kafka source `create_sql`, returning `{"topic": <text>, "group_id_prefix": <text|null>, "connection_id": <text>}`; returns JSON `null` for non-Kafka-source statements), and `parse_source_export_details` (extracts source-export metadata from a `CREATE TABLE ... FROM SOURCE` or non-progress `CREATE SUBSOURCE ... OF SOURCE ...` statement, returning `{"source_id": <text>, "external_reference": [<text>, ...], "envelope_type": <text|null>, "key_format": <text|null>, "value_format": <text|null>}`; `envelope_type`, `key_format`, and `value_format` are always null for `CREATE SUBSOURCE` statements; returns JSON `null` for progress subsources and any non-source-export statement). Also provides `parse_connection_details` (extracts connection metadata from a `CREATE CONNECTION` `create_sql` string; for Kafka connections returns `{"brokers": [...], "progress_topic": <text|null>}`; for SSH connections returns `{"public_key_1": <text|null>, "public_key_2": <text|null>}`; for AWS connections returns `{"auth_kind": "assume-role"|"credentials", "endpoint": <text|null>, "region": <text|null>, "access_key_id": <text|null>, "access_key_id_secret_id": <text|null>, "secret_access_key_secret_id": <text|null>, "session_token": <text|null>, "session_token_secret_id": <text|null>, "assume_role_arn": <text|null>, "assume_role_session_name": <text|null>}`; returns JSON `null` for other connection types and non-connection statements).
Helper functions include `jsonb_datum_to_u64`, `jsonb_datum_to_acl_mode` (shared decoder for `AclMode` objects used by both `parse_catalog_privileges` and `parse_catalog_acl_mode`), and `jsonb_datum_to_role_id`. The `PostgresPublicationDetailsSubset` struct is a local prost message that re-declares the two proto tags needed (`slot` at tag 2, `timeline_id` at tag 3) to avoid a dependency cycle with `mz-storage-types`.
