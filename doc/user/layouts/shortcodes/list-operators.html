Operator | Description ---------|------------- listany || listany | Concatenate the two lists. listany || listelementany | Append the element to the list. listelementany || listany | Prepend the element to the list. listany @> listany | Check if the first list contains all elements of the second list. listany <@ listany | Check if all elements of the first list are contained in the second list. listany < listany, and likewise <=, >, >=, =, <> | Compare the two lists element by element. The first pair of elements that differ decides. A _NULL_ element is greater than any non-_NULL_ element, whatever `NULLS FIRST` or `NULLS LAST` says, since those only place values that are _NULL_ as a whole. A list is greater than any shorter list that it starts with. `ORDER BY`, `min`, and `max` order lists the same way.
